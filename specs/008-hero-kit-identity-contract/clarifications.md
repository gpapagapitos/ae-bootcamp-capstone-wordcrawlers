# Spec 008 Clarifications

## Decisions

1. Locked MVP heroes

- Decision: Duelist and Arcanist are the two MVP heroes.

2. Duelist signature

- Decision: Duelist uses a chain mechanic that rewards consecutive valid submissions with escalating conditional bonuses.

3. Arcanist signature

- Decision: Arcanist uses enemy-hex conversion effects for control and burst timing.

4. Resource model

- Decision: Heroes use shared global resources (energy, enemy hex) and do not add a unique gauge in MVP.

5. Starter deck size

- Decision: Each hero starts with 12 cards and one hero-specific starter relic.

6. Balance variance threshold

- Decision: Internal seed-suite win-rate delta between heroes should stay within 8 percentage points.

7. Hero pool weighting

- Decision: Hero-specific rewards use elevated weighting, while neutral pool remains always eligible.

## Remaining Risks

- Hero identity can blur if neutral pool overdominates early rewards.
- Chain and hex mechanics may diverge in complexity burden for new players.
- Win-rate variance target may require frequent content retuning as pools expand.
