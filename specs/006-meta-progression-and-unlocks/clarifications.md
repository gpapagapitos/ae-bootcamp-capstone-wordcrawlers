# Spec 006 Clarifications

## Decisions

1. Unlock ownership scope

- Decision: Gameplay unlocks are profile-global, not hero-locked.

2. Cosmetic unlock scope

- Decision: MVP cosmetics include hero banner variant and card-frame variant.

3. Early pacing target

- Decision: First unlock target is within 2-3 runs for median internal playtest performance.

4. Loss reward floor

- Decision: Losses always grant at least 35% of baseline win currency for equivalent depth.

5. Inflation control

- Decision: Apply soft diminishing returns after daily threshold for extended sessions in MVP test mode only.

6. Reset behavior

- Decision: Profile reset clears currency and unlocks; does not delete active run save.

7. Balance test mode

- Decision: Meta progression can be fully disabled via deterministic fixture profile.

## Remaining Risks

- Unlock pricing can accidentally force one dominant path.
- Cosmetic production effort may slip if art pipeline is not constrained.
- Diminishing returns may feel punitive if surfaced poorly in UI.
