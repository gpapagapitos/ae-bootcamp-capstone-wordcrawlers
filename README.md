# Wordcrawlers

Wordcrawlers is a single-player word-building roguelite inspired by deckbuilding dungeon crawlers and the feel of Paperback Adventures.

This project is capstone-oriented and intentionally follows spec-driven development:

1. Define rules and adaptation constraints.
2. Write clear feature specs.
3. Clarify edge cases before implementation.
4. Generate technical plans and task lists.
5. Implement only after spec sign-off.
