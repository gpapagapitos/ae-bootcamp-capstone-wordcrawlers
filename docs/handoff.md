# Evolving Handoff

This document is session-friendly and should be updated frequently.

## How To Update

1. Update tasks via board script commands.
2. Render board markdown.
3. Append a new handoff snapshot.

Commands:

- npm run board:render
- npm run board:check
- npm run handoff:snapshot
